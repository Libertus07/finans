## 2024-05-21 - Unstable Props Defeating Memoization
**Learning:** In React, passing unstable functions (like inline arrow functions or unmemoized functions) as props to a child component defeats `React.memo`, even if the child component doesn't actually use or explicitly depend on those props. In `App.jsx`, `getProfitabilityWarnings` was defined as a standard function inside the component body, creating a new reference on every render of `App.jsx` (which handles all state). This caused the heavily loaded `Dashboard` component to constantly re-render.
**Action:** When a parent component manages significant state and passes helper functions down to heavily loaded, lazily-loaded or memoized child components, ALWAYS wrap those helper functions in `useCallback` to preserve reference stability and allow `React.memo` to work effectively.
