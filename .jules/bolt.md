## 2024-10-07 - Cached Intl formatters performance win
**Learning:** Instantiating `Intl.NumberFormat` repeatedly in a tight loop is a massive performance bottleneck. In this React application, `formatCurrency` is called dozens of times per render (74 occurrences of `formatCurrency` in `src/`). Caching the formatter instance yielded a 98% execution time improvement in a 10,000 iteration benchmark (645ms down to 10ms). Note: the same could be applied to `Intl.DateTimeFormat` but requires a manual `isNaN` check because `.format(new Date('invalid'))` throws a RangeError whereas `.toLocaleDateString` returns "Invalid Date" safely.
**Action:** Always cache `Intl.NumberFormat` and `Intl.DateTimeFormat` instances at the module level instead of recreating them inside formatting utility functions.
