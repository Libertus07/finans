## 2024-05-24 - Unstable Props and Dead Code Defeating React.memo
**Learning:** Defining helper functions inside component bodies (like `App.jsx`) and passing them as props creates unstable references on every render. Even if the child component is wrapped in `React.memo`, these unstable function references will defeat the memoization and trigger expensive re-renders. Furthermore, if the function is unused dead code (e.g. `getProfitabilityWarnings` passed to `Dashboard`), it unnecessarily hurts performance for no benefit.
**Action:** When attempting to memoize components via `React.memo`, especially lazy-loaded heavy views like Dashboards, carefully trace all props. If any prop is a function created inside the parent's render cycle without `useCallback`, it must be stabilized, moved outside the component, or deleted entirely if it's dead code.
