## 2024-05-18 - Dashboard Memoization Anti-Pattern
**Learning:** `Dashboard` component is lazily loaded and receives heavily calculated objects/functions from `App.jsx`, but it is not wrapped in `React.memo`. `App.jsx` acts as the central state manager for Firebase snapshots, causing `App` to re-render very frequently. Even worse, `App.jsx` passes `getProfitabilityWarnings` as a prop to `Dashboard`, which is instantiated on every render, and this function isn't even used inside `Dashboard.jsx`.
**Action:** Always wrap lazily loaded page components in `React.memo` if their parent acts as a global state manager (like `App.jsx` here). Ensure unused props that break referential equality (like `getProfitabilityWarnings`) are removed from the prop list to allow memoization to work properly.
