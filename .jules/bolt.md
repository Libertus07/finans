## 2024-05-12 - Dashboard Component React.memo & Unused Props Stabilization
**Learning:** In the `App.jsx` architecture, passing newly instantiated helper functions (like `getProfitabilityWarnings`) down to lazily-loaded child components (like `Dashboard`) creates unstable prop references that defeat `React.memo`. Even if the child component doesn't actively use the prop, the unstable reference causes continuous re-renders. It's crucial to stabilize these functions with `useCallback` rather than deleting them, preserving business logic while ensuring performance.
**Action:** Always wrap helper functions defined in central state managers with `useCallback` before passing them as props to memoized components, and wrap lazily loaded components like `Dashboard` in `React.memo`.
